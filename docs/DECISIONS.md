numbers (C-xx) refer to the Dawabag Regulatory Compliance Rulebook
(https://claude.ai/code/artifact/472ce7a8-885a-4402-932e-010e211622f4, owner access).

| 2026-10-02 | **New products to complete (Sprint 31):** categories and HSN codes are chosen from lists kept on the server, with Alt+C / "+ New" to add one; the description for buyers is optional when saving and approving; a "Non-scheduled" drug schedule is added. | `product_categories` and `hsn_codes` (migration 26); admins and pharmacists add entries, audited. No code rule needed a buyer description for a listed product (C-17 asks for the pack declarations, C-19 for review of whatever copy exists); a description added later goes back to the pharmacist's Product copy review. | 2026-10-01 | **Partner stock counts towards availability, under each partner's own stock ledger.** A medicine held only by an approved partner pharmacy can be bought. | Search, product page and cart read partner stock from `partner_inventory` (read-only, `services/stock/partnerStock.ts`) with the same eligibility as allocation; nothing is copied into Dawabag's batches. | 2026-10-01 | **Free delivery for retail orders of ₹499 or more** (medicines after any coupon, before GST). | 2026-10-02 | **Adopt the DAWA BAG brand** (owner's design: DAWA \| BAG logo, teal + green, tagline "Your Life Saving Companion", rounded fields/buttons). | Web and app restyled to the brand; Direction A layout and flows stay (mobile+OTP login, OTP password reset, consent + 18+ + business sign-up, address at checkout). | 2026-10-01 | **Design Direction A (clinical trust) and rehearsal R2 (recorded journeys).** All dates and times in IST. | Web and app home: trust strip, prescription card, category tiles, bottom bar on phones; compact legal footer on phones. | 2026-09-30 | **Sprint 5 defaults (proposed by the developer — confirm or change).** Returns: damaged, wrong or missing items reported within 48 hours of delivery; expired, near-expiry (≤ 90 days left) or quality claims within 30 days; recalled batches any time. No change-of-mind returns. Refunds go back the way the buyer paid (credit bill reduced, then card/UPI, then wallet); delivery charges are refunded only on cancellation. Buyers may cancel until packing starts. Delivery code required for prescription shipments only. | All four values are `app_settings` keys (`returns.*`, `delivery.handover_code_scope`) the admin can change. Returned medicines are never restocked (destroyed or sent back to the supplier). Existing products' descriptions stay hidden until a pharmacist approves the copy. | C-26, C-37, C-19 |
| 2026-09-30 | **Order allocation.** Orders above ₹10,000 that Dawabag can deliver within 24 hours are filled from Dawabag's own stock first; partners fill only lines Dawabag cannot. All other orders go to the nearest in-stock seller (Dawabag counted as a seller), then higher rating, then earliest expiry (FEFO). *Interpretation of the owner's answer — confirm.* | Threshold and hours live in `app_settings` (server), not code. Each order is split into one shipment per seller; each seller issues its own invoice. Cold-chain lines go only to sellers with confirmed cold storage. | C-05, C-25 |
| 2026-09-30 | **Partner lines sell at Dawabag's catalogue price** for the buyer's type (offer / PTR / PTS / institutional). | Partners accept catalogue prices when listing; the buyer never sees seller-specific prices. Settlement pays the partner the line value less commission, finding fee, GST on those fees, TCS and TDS. | C-16, C-32 |
| 2026-09-30 | **Refills:** reminder a few days before the refill date, then the server creates the order; if the buyer has an active payment mandate it is charged automatically, otherwise the buyer gets a pay link. | Reminder doubles as the pre-debit notice required for e-mandates. Prescription lines still need a valid prescription; those orders wait for pharmacist verification before any charge. | C-08, C-45 |
| 2026-09-30 | **Standing rule: modular software, no monolithic HTML.** | No single-file HTML applications (as the earlier PharmaMES-style builds were). Code is split by responsibility: backend routes → controllers → services → utils; web pages built from components in `src/components/*` and logic in `src/lib/*`; mobile screens, widgets, providers and services in separate files. New features get their own modules, not additions to one large file. | — |
| 2026-09-30 | **Standing rule: the server is the single source of truth.** No local write/storage in any app or service: no files, blobs, JSON or databases on the device, browser or app-server disk. No data has two authorities. | All business data (cart, profile, customer type, KYC status, pincode, orders) lives only in PostgreSQL and is fetched from the API. Files (KYC documents, prescriptions, invoices) go only to the server object store (S3, ap-south-1). Web sessions use an httpOnly, Secure, SameSite cookie set by the server; mobile keeps only the refresh token in the OS keychain; access tokens live in memory. No localStorage, zustand persist, Hive, shared_preferences or local disk writes. | C-41, C-44 |
| 2026-09-30 | **Marketplace partners invoice as seller of record.** Dawabag is the platform; the licensed partner whose premises dispatch the goods issues the tax invoice. | Supersedes URS v3.1 "Dawabag invoices the customer, partner dispatches". Sprint 3 must build partner-issued invoices (partner GSTIN, drug licence and invoice series), commission/fee invoices from Dawabag to the partner, and TCS (CGST s.52) / TDS (s.194-O) in settlements. Orders fulfilled from Dawabag's own stock keep Dawabag as seller. | C-05, C-32, C-33 |
| 2026-09-30 | **Wholesale drug licences are Forms 20B / 21B** (not 20C / 21C). | `drug_license_type` values are `dl20`, `dl21` (retail) and `dl20b`, `dl21b` (wholesale) in the database, API, web and mobile. URS v3.1 text still says 20C/21C and needs a revision. | C-02, C-11 |
| 2026-09-30 | **No doctor referral rewards.** | `doctor_referrals` table, `doctor_profiles.bonus_points` and `GET /doctors/me/referrals` removed. Do not reintroduce any reward, discount or points for doctors tied to referrals or prescriptions. | C-20 |
